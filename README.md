# 🧠 Vanguard OS — Sovereign Intelligence GUI Environment

Интерактивная интеллектуальная графическая оболочка с интегрированным локальным ИИ-ядром и многопоточной подсистемой телеметрии. Проект представляет собой полную эволюцию архитектуры софта от прототипа на Python до высокопроизводительной модульной системы на Rust.

## 📁 Структура репозитория
* `/vanguard_os_legacy` — Первоначальная версия операционной системы на Python. Включает в себя кастомный командный шелл, парсер слеш-команд, подсистему аудита железа через `psutil` и модульные юнит-тесты `pytest`.
* `/vanguard_os_rust` — Актуальное высокопроизводительное ядро на **Rust (Egui)**. Архитектура построена на базе раздельных скриптов-модулей, Dual-Mode Terminal Link (одновременный вывод в графику и консольный лаунчер терминала), атомарных контейнеров `Arc<Mutex>` и асинхронных каналов `mpsc`.

## 🚀 Архитектурные особенности Rust-версии (Middle-уровень)
1. **Multithreading Telemetry Daemon:** Мониторинг процессора, памяти и дисков вынесен в изолированный фоновый поток (Thread Daemon) и синхронизируется с графическим циклом без задержек интерфейса.
2. **Window Server Engine:** Собственный оконный менеджер `VanguardWindow` для нативного рендеринга изолированных приложений (`Notes`, `Matrix`, `Cleaner`, `App Registry`) через обобщенные типы (Generics) и замыкания `FnOnce`.
3. **Asynchronous Shell Routing:** Маршрутизация системных слеш-команд через потокобезопасные каналы связи для неблокирующего стриминга ИИ-токенов.

## 🛠️ Инструкция по запуску Rust-версии
1. Убедитесь, что в системе установлен компилятор Rust и пакетный менеджер Cargo.
2. Перейдите в папку проекта: `cd vanguard_os_rust`
3. Запустите лаунчер терминала и графическую среду оболочки: `cargo run`
